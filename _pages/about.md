## Current focus

- Secure and delay-aware control over encrypted computation pipelines
- Privacy-preserving dynamical systems and robust optimization under distributional uncertainty
- Learning-based output feedback control with explicit verifiability and performance guarantees

## Selected work

- **Co-Design of Cryptographic Parameters and Delay-Aware Feedback Gain for Encrypted Control Systems** (2026). <https://arxiv.org/abs/2604.14774>
- **A Distributionally Robust Optimal Control Approach for Differentially Private Dynamical Systems** (2026). <https://arxiv.org/abs/2603.18364>
- **Inverse Learning-Based Output Feedback Control of Nonlinear Systems with Verifiable Guarantees** (2026). <https://arxiv.org/abs/2603.10292>
- **Privacy-Preserving Fully Distributed Gaussian Process Regression** (2025). <https://arxiv.org/abs/2512.05473>
- **Documentation on Encrypted Dynamic Control Simulation Code using Ring-LWE based Cryptosystems** (2025). <https://arxiv.org/abs/2504.13403>
